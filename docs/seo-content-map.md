# Go Marketing SEO Content Map

This document is the working SEO content plan for Go Marketing. It is designed to keep future website updates focused on the agency's strongest positioning: a Sydney-based bilingual marketing agency helping businesses communicate more clearly across Chinese-Australian and mainstream Australian markets.

The plan intentionally avoids invented claims, public client names, fake results, awards, certifications, or testimonials.

## Current State

Technical SEO is now in place:

- Canonical URLs and hreflang are set across bilingual pages.
- `sitemap.xml` and `robots.txt` are live.
- Open Graph, Twitter Card and JSON-LD metadata are generated for primary pages.
- A weekly and push-triggered GitHub Action runs `npm run seo:check`.

Main remaining growth work:

- Build stronger search-focused content around bilingual marketing, Chinese community growth and Sydney service industries.
- Rewrite or replace generic insights that do not support the agency's specialist positioning.
- Use Google Search Console data to prioritise pages that already have impressions but weak rankings.
- Strengthen service and industry pages with clearer search intent, internal links and conversion pathways.

## Positioning Guardrails

Use this framing consistently:

- Sydney-based bilingual marketing agency.
- Bridge between Chinese-Australian and mainstream Australian audiences.
- Commercially practical digital marketing partner, not a generic full-service menu.
- Strong fit for hospitality, property, wellness, dental and service-based businesses.
- Bilingual value means audience behaviour, trust mechanisms, platform logic and local market context, not simple translation.

Avoid:

- One-stop agency language.
- Fake performance metrics.
- Overclaiming results.
- Publishing confidential client names.
- Treating every past industry as equal strategic focus.
- Turning Chinese-Australian audiences into a standalone industry.

## Internal Linking Rules

Every new article should link to:

- One core service page.

- One related article.
- Contact section or service overview.

Every service page should link to:

- Services overview.
- Relevant supporting service pages.
- Target market page.
- One or two relevant insights.

Every industry section should link to:

- Chinese Community Growth if Chinese-speaking audience trust is relevant.
- Website Messaging & Digital Credibility if service-page clarity is relevant.
- Bilingual Brand & Content Strategy if positioning and communication quality are central.

## Metadata Rules

Titles:

- Keep page titles specific and search-readable.
- Lead with the topic, then Go Marketing if needed.
- Avoid vague titles like "Our Blog Posts".

Descriptions:

- Mention Sydney where locally relevant.
- Mention bilingual or Chinese-Australian context only when it is genuinely part of the page.
- Avoid invented outcomes or exaggerated claims.

Structured data:

- Use existing metadata generator.
- Do not hand-edit JSON-LD blocks unless the generator is updated too.

Commands:

```bash
npm run seo:metadata
npm run seo:check
```

## Google Search Console Checklist

This requires account access and should be done by the site owner or while screen-sharing.

1. Add or confirm property for `https://gomarketing.net.au`.
2. Submit sitemap: `https://gomarketing.net.au/sitemap.xml`.
3. Check Pages indexing report.
4. Check whether canonical and alternate language pages are being accepted.
5. Export queries with impressions but low average position.
6. Prioritise pages where impressions already exist.
7. Review mobile usability and Core Web Vitals.
8. Re-submit important pages after major rewrites.

Useful Search Console exports:

- Top queries by impressions.
- Top pages by impressions.
- Queries with average position 8-30.
- Pages with impressions but low click-through rate.

## Measurement Plan

Track monthly:

- Organic clicks.
- Organic impressions.
- Average position for target queries.
- Click-through rate by page.
- Indexed page count.
- Contact form submissions from organic traffic.
- Phone and email clicks if analytics tracking is configured.

Avoid judging SEO by rankings alone. A service business should care about qualified enquiries, trust and better-fit traffic.

## Manual Review Needed

Before publishing new proof or case-study content, confirm:

- Client identity can be public.
- Any performance result is real and approved.
- Any industry-specific claim is accurate.
- Phone, address and contact details are consistent across the website, Google Business Profile and social profiles.
- No medical, financial or legal result claims are implied without evidence.
